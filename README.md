# Vespine Labs

The Vespine Labs studio front page. This is a dependency-free static site built with HTML, CSS, and a small amount of JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. For example:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy

The site can be hosted by any static web host. The custom domain `vespinelabs.com` can be connected once the hosting provider and DNS access are available.
